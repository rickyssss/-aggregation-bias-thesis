# queue/candidate_pairs.csv について

## これは何のためのファイルか

この卒業論文では、「集計単位（データをまとめる単位）を変えると、同じデータでも統計的な結果（相関関係など）が違って見えることがある」という現象を、実際の公式統計データを使って確認します。

たとえば日本なら「都道府県」という粗い単位で見た人口と所得の関係と、「市区町村」というより細かい単位で見た人口と所得の関係が、実はズレていることがある――というようなことを、複数の国のデータで検証したいわけです。

`candidate_pairs.csv` は、そのために使えそうな「粗い集計単位のデータ」と「細かい集計単位のデータ」の組み合わせ（ペア）の候補を、国ごとにリストアップしたものです。ここに載っているURLは、すべて実際にアクセスして中身が本物の統計データ（表やCSVファイルなど）であることを確認済みです。ただし、まだ「この組み合わせで本当に分析する」と決めたわけではないので、これから研究者が中身をよく見て、実際に使うかどうかを選ぶための「候補リスト（キュー）」という位置づけです。

## 各列の意味

| 列名 | 意味 |
|---|---|
| `id` | 候補ペアの通し番号。管理用です。 |
| `country` | どの国のデータか（日本、アメリカ、イギリスなど）。 |
| `variable` | 比較する変数（人口、所得、出生数など）。同じ変数を粗い単位・細かい単位の両方で見比べます。 |
| `coarse_level_name` | 「粗い集計単位」の名前（例: 都道府県、州、Regionなど）。 |
| `coarse_source_name` | 粗い単位のデータを出している機関・統計の名前（例: 総務省統計局のSSDSE、e-Statの人口動態調査など）。 |
| `coarse_source_url` | 粗い単位のデータが実際に取得できるURL。すべて政府・政府系機関の公式サイトで、無料・登録不要でアクセスできることを確認済みです。 |
| `fine_level_name` | 「細かい集計単位」の名前（例: 市区町村、郡、Local Authorityなど）。 |
| `fine_source_name` | 細かい単位のデータを出している機関・統計の名前。 |
| `fine_source_url` | 細かい単位のデータが実際に取得できるURL。こちらも公式サイトで無料・登録不要であることを確認済みです。 |
| `notes` | データを使う上での注意点・補足情報（ファイル形式、対象年、データの取得方法、集計単位ごとに定義や算出方法が微妙に違う場合の注意など）。分析前に必ず目を通してください。 |
| `status` | このペアを実際に検証で使うかどうかの進み具合を示すステータス。現時点ではすべて `pending`（＝まだ手をつけていない・検討中）にしてあります。実際に使うと決めたら `in_progress` や `done` のような値に、使わないと決めたら `rejected` のような値に、研究者自身で書き換えていく想定です。 |

## 使い方の想定

1. このCSVを開いて、`country` や `variable` を見ながら、実際に分析してみたい組み合わせを選ぶ。
2. `coarse_source_url` と `fine_source_url` に実際にアクセスし、`notes` に書かれた注意点を確認しながら、必要なデータ（人口や所得の数値）をダウンロードする。
3. 粗い単位のデータと細かい単位のデータを使って、実際に相関係数などを計算し、集計単位によって結果がどう変わるかを比べる。
4. 使った・使わなかった結果を `status` 列に反映させて、進捗を管理する。

## 補足

- 今回、韓国（KOSIS）についても同様の条件で候補を探しましたが、都道府県相当（市道）レベルのデータは公式サイト上で内容を確認できたものの、市区郡（市郡区）レベルのデータについては、サイトの仕組み上（JavaScriptで表示される形式のため）中身が本物のデータであることを機械的に確認できませんでした。そのため、確実性を優先し、韓国のペアはこのCSVには含めていません。ブラウザで直接KOSISのサイトを開いて確認すれば見つかる可能性があります。
- 一部の行（id=8のイギリスのペアなど）は、粗い単位と細かい単位でデータの算出方法が完全には一致していない可能性があるものも、参考候補として`notes`に注意書き付きで残してあります。分析に使う前に必ず内容を確認してください。
